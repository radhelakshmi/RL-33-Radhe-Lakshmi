# RL-33 Lightweight Website

## Folder structure
- `index.html` — main website file
- `assets/` — optimized WebP images used by the website

## GitHub Pages upload
1. Open your GitHub repository.
2. Replace the old `index.html` with this `index.html`.
3. Upload the complete `assets` folder with all four WebP files.
4. Commit the changes.
5. Open your GitHub Pages website and refresh it.

**Important:** Keep the `assets` folder in the same directory as `index.html`. Do not rename the image files unless you also update their names in `index.html`.
